# CargoShare – Smart Railway Cargo Booking Platform

A college project prototype for digital railway cargo-space booking.

## Features
- 🔍 Search trains by Source → Destination → Date → Time
- 📦 Real-time cargo capacity display
- 🎫 Digital booking with QR code
- 📍 Live cargo tracking
- 🛡️ Admin portal for train & capacity management
- 👤 Trader registration & login

## Running Locally
```
python -m http.server 3000
```
Then open: http://localhost:3000

## Note
This is a prototype. Train and cargo-capacity data is managed via the CargoShare Admin Portal.
Not connected to live Indian Railways data.
